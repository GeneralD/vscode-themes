# KOKO 幸祜

A soft, dreamy dark theme inspired by gentle pastels and quiet elegance. Lavender pinks, mint greens, and warm golds float on a deep twilight canvas.

**Palette:** ![#e8a0b8](https://via.placeholder.com/16/e8a0b8/000000?text=+) ![#88c8a0](https://via.placeholder.com/16/88c8a0/000000?text=+) ![#b088e0](https://via.placeholder.com/16/b088e0/000000?text=+) ![#e8c888](https://via.placeholder.com/16/e8c888/000000?text=+) ![#141020](https://via.placeholder.com/16/141020/000000?text=+)

## Features

- Semantic highlighting support
- Full coverage of editor, UI, terminal, and syntax colors

## Installation

1. Install the extension
2. Press `Cmd+K Cmd+T` (Mac) or `Ctrl+K Ctrl+T` (Windows/Linux)
3. Select **KOKO 幸祜**
