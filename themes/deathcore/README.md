# Deathcore

A brutal dark theme forged in the void. Blood reds, bone whites, and decayed purples emerge from an abyss of pure black — as heavy as a breakdown.

## Features

- Semantic highlighting support
- Full coverage of editor, UI, terminal, and syntax colors

## Installation

1. Install the extension
2. Press `Cmd+K Cmd+T` (Mac) or `Ctrl+K Ctrl+T` (Windows/Linux)
3. Select **Deathcore**
