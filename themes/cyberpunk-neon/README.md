# Cyberpunk Neon

A neon-drenched dark theme inspired by cyberpunk aesthetics. Vivid pinks, electric cyans, and deep purples glow against the void of a digital underworld.

**Palette:** ![#ff2d95](https://via.placeholder.com/16/ff2d95/000000?text=+) ![#00fff2](https://via.placeholder.com/16/00fff2/000000?text=+) ![#7b61ff](https://via.placeholder.com/16/7b61ff/000000?text=+) ![#ffb800](https://via.placeholder.com/16/ffb800/000000?text=+) ![#0a0a1a](https://via.placeholder.com/16/0a0a1a/000000?text=+)

## Features

- Semantic highlighting support
- Full coverage of editor, UI, terminal, and syntax colors

## Installation

1. Install the extension
2. Press `Cmd+K Cmd+T` (Mac) or `Ctrl+K Ctrl+T` (Windows/Linux)
3. Select **Cyberpunk Neon**
